# Task 4: Sentiment Analysis on Social Media Data

Part of the Prodigy Infotech Data Science Internship.

## Objective
Identify and visualize sentiment patterns in social media data to
understand public opinion toward specific topics.

## Dataset
Twitter Entity Sentiment Analysis dataset (training + validation files).

## Approach
- Combined both files and dropped rows with missing sentiment/topic
- Overall sentiment distribution
- Top 10 topics by tweet volume
- Sentiment breakdown for the top 10 topics

## Key findings
- 75,682 tweets across 32 topics
- Negative was most common (22,808), then Positive (21,109),
  Neutral (18,603) and Irrelevant (13,162)
- Madden NFL and Facebook had the highest share of negative sentiment
- Opinions were polarized: strong positive or negative over neutral

## Tools
Python, Pandas, Matplotlib, Seaborn
